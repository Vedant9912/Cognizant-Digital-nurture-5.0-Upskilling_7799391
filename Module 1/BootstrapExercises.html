Ex 19 — Customization with Sass

// _variables.scss — Exercise 19.2

// Override Bootstrap primary color
$primary: #1a3c5e;

// Override border-radius
$border-radius: 0.6rem;
$border-radius-pill: 50rem;

// Import Bootstrap AFTER variable overrides
@import "bootstrap/scss/bootstrap";

// Terminal setup — Exercise 19.1

npm init -y
npm install bootstrap sass

# Add to package.json scripts:
# "build-css": "sass scss/custom.scss css/bootstrap.min.css --style compressed"

npm run build-css

The custom primary colour and border-radius applied via CSS variables above (:root overrides) demonstrate the visual effect of Sass customisation in this CDN-based demo.
